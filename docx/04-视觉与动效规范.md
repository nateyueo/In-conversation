# 言间｜视觉与动效规范

版本：V0.3 阅读修正版 · 日期：2026-10-24 · 最新 img 参考优先；未实测适配仍为验收目标

## 1. 本文的约束与设计目标

**让词语和句子成为画面中心，让动作可以直接看懂。** 用户最新要求严格参照 img 中五张新图，覆盖旧词浅句深设计。两种模式统一暖纸背景，居中“言间”、金棕胶囊切换、花枝与水墨装饰；保留发现/收藏/数据三导航与实际功能。

正文、释义、按钮和图表均为原生 Compose。图片只作装饰，不将整张效果图作为界面。参考图数字不是用户数据。

卡片上下滑读全文，点击翻面只看真正释义，详情用按钮打开；出处技术字段默认折叠。设置同位置再次点击关闭。

本版不使用霓虹、强渐变、玻璃模糊、发光描边、复杂拟物按钮、大面积装饰插画、密集教学文案。页面需要的是阅读感和操作反馈，而不是把技术实现说明放进产品。

## 2. 设计变量

### 2.1 颜色

| Token | 词语与句子统一值 | 用途 |
|---|---|---|
| background | #F4EDDF | 页面与系统栏 |
| surface | #FFFAEF | 阅读卡片、列表与弹层 |
| surfaceSubtle | #EDE3CF | 胶囊轨道 |
| textPrimary | #363C30 | 正文与标题 |
| textSecondary | #898675 | 辅助文字 |
| accent | #AA8453 | 选中项、操作 |
| onAccent | #FFFFFF | 实心按钮文字 |
| line | #E7DDC9 | 轻分隔 |

状态栏与系统导航栏均用深色图标。模式切换仅改变内容与选中状态，不切深色主题。本次颜色以参考图与实际截图核对，不沿用旧配色的对比度计算结果。

### 2.2 字体与字号

| 内容 | 建议字号 / 行高 | 字重与样式 | 约束 |
|---|---|---|---|
| 双字词主卡 | 56sp / 72sp | 中文衬线，常规 | 两字间距约 0.08em，依字形微调 |
| 四字词主卡 | 44sp / 60sp | 中文衬线，常规 | 不把四字词挤成细长一行 |
| 句子主卡 | 28–34sp / 44–50sp | 中文衬线，常规 | 左对齐或自然分句，不强行居中每行 |
| 页面标题 | 24sp / 32sp | 常规或中等 | 不与词句主视觉争抢 |
| 卡片背面释义 | 20sp / 30sp | 常规 | 优先一句话，长释义可滚动 |
| 正文与列表标题 | 16sp / 24sp | 常规 | 遵循系统字体缩放 |
| 来源、标签、辅助信息 | 13–14sp / 20sp | 常规 | 不用极淡灰隐藏关键信息 |
| 按钮与底部导航 | 14–15sp / 20sp | 中等 | 文字始终保留 |

默认采用 Android 系统字体；中文衬线无法可靠取得时使用系统回退。后续确定独立字体前核对字体许可、中文覆盖和包体；不因效果图中的字体而默认获得其商用或分发授权。数字和操作标签用清晰的无衬线，中文主词可用衬线。

内容必须完整显示。字号缩小只能在设计范围内进行，不能为了维持固定卡高无限缩字。超过舒适范围时让卡片内部或页面滚动；不得在主要句子末尾用省略号隐藏内容。大字体模式允许布局变高、操作区换行，仍能访问详情与评分。

### 2.3 网格与形状

| 变量 | 建议值 | 说明 |
|---|---|---|
| 页面横向边距 | 24dp；窄屏 20dp | 所有页使用同一关键线 |
| 基础间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48dp | 不随意增添大量零散间距 |
| 主卡片圆角 | 28dp | 明确卡片实体感 |
| 次级卡片圆角 | 20dp | 收藏项、统计容器 |
| 小按钮圆角 | 14dp | 常规操作 |
| 分段开关圆角 | 高度的一半 | “词语 / 句子”全局开关 |
| 边框 | 1dp | 大部分容器只用轻边线 |
| 阴影 | 0–2dp，克制 | 只在需要区分层级时使用 |
| 图标视觉尺寸 | 20–24dp | 实际可点击范围至少 48×48dp |
| 内容最大宽度 | 560dp | 平板/横屏居中，避免无限拉长 |

页面遵循系统状态栏、导航栏、刘海和键盘安全区。外部背景可以延伸到系统栏，词句与操作不得被遮挡。Android 15 及以上相关 edge-to-edge 行为须按目标 SDK 正确处理，不能用固定的状态栏高度代替窗口 inset。[2]

## 3. 页面版式

### 3.1 通用框架

顶部居中品牌“言间”，下方简短副标题与216dp宽、48dp高的词句切换；右侧设置，左侧轻花枝装饰。选中项金棕底白字。

底部三个入口：**发现、收藏、数据**，每个保留图标与文字，选中项以强调色和小型底标表达。导航容器不加厚重悬浮阴影。复习由收藏进入，独立沉浸显示并保留退出/返回入口；不为复习再添加第四个底部导航。

切换模式不重置用户所在的一级页面。每种模式分别保存当前卡片、列表筛选和滚动位置。顶部切换、设置与系统返回不能出现“点了没反应”的假按钮。

### 3.2 发现

从上到下只有清晰的层次：顶部模式开关 → 小型章节/分类行 → 主卡片 → 操作区 → 底部导航。主卡片在可用高度中占主要部分，参考竖屏宽 360–430dp 时卡宽为屏宽减两侧边距，卡高约 390–480dp，具体按系统安全区和文字缩放自适应。

词卡以词语为视觉中心，可附极轻的词性或两字/四字标记；不把来源、评分解释、教学提示全部放在卡面。句卡优先左对齐，使用一条细短线或克制引号辅助阅读。卡片底部可保留一行作品名；正式内容来源未核验时不伪造作品名，开发样例明确以演示内容呈现。

卡片底部保留收藏、不再推荐和详情按钮；左右滑换卡，上下只滚动正文。上一条、下一条也可点击。卡片有限高度，切条目/卡面重置滚动，正文不省略。

### 3.3 收藏

标题与数量一行；搜索框低对比容器；筛选胶囊数量受控；内容列表以文字为主体。每条最多显示词句、短释义、掌握状态和来源一行。收藏图标已选中，移除使用可撤销反馈。

底部固定“开始复习”，同时展示当前到期数量；按钮和底部导航之间留出安全距离。无到期内容时改成真实状态“暂无到期内容”，可另选主动练习；不能把未来到期项悄悄当作今日任务。没有收藏时展示一个短句“还没有收藏”与“去发现”，不堆插画和长教程。

### 3.4 复习

顶部包含返回、复习进度与必要操作；下一行是“不熟悉 / 熟悉 / 已会”三个分类筛选；初学内容用独立的“未学习”入口或可识别标记，不硬塞进“不熟悉”。筛选是低强调度控件，评分是底部固定动作，两者位置、轮廓和反馈明显区分。

正面卡片只展示词语或句子。点击卡片翻面，背面只展示短释义或简短表达意图。底部评分“不熟悉 / 熟悉 / 已会”在正面时不可提交；展示答案后变为可用。使用文字、边框、选中状态共同表达，不能只靠红黄绿分辨。

详情按钮展示正文、释义及可读作品名，出处默认折叠。关闭后返回原卡与卡面。仅有真实释义的卡片可学习评分，评分成功才前进；滑动不产生评分。

### 3.5 详情

详情面板首屏只展示正文、真实释义、简短作品名与可读语境。网址、文件路径、源版本、署名、许可和状态字段位于默认关闭的“出处与授权”。个人内容的来源链接不直接输出为语境。

空字段省略，缺释义诚实提示。完整来源继续保存在内容数据与导出中；默认折叠不等于删除来源。

详情内部正常滚动，关闭按钮与系统返回始终可用；本轮不依赖拖拽关闭。

### 3.6 数据

时间范围为今日/近7日/近30日/全部。首层四项大数字：浏览内容、复习次数、复习内容、新增收藏；第二层为当前收藏的四状态分布环（含待学习）；第三层为真实每日复习柱形图，连续日期补零，可水平滚动。

“今日行为”和“当前存量”分别标明口径。初学未评分单独显示；不能把其计入不熟悉后又宣称评估过。未接入真实调度模型或数据不足时，记忆曲线区域只显示“积累复习记录后显示”，不使用装饰折线充当用户预测。

图表使用最多三到四种低饱和色，并附标签与数值。零值采用正常字体，不画出无意义的满圆或虚构百分比。

### 3.7 设置与导入

设置与主页面共用顶部框架，右侧图标使用选中背景或关闭符号。**同一位置再次点击即关闭设置，回到进入前的页面、模式和内容。** 系统返回行为相同。非破坏性偏好即时保存；有未确认导入草稿时按流程保留或取消，不能误写数据库。

设置分组控制在内容偏好、数据管理、阅读体验三组。句子比例用一个清晰滑杆显示“实用 60% / 经典 40%”，两个数总和必须为 100%；类型选择使用可选标签。不把调度公式、数据库名、内部状态码写进用户界面。

导入依次展示文件名、识别数量、错误/重复数量、内容预览和确认按钮。导入成功才弹简短反馈；失败显示可行动原因并保留原数据。备份入口与仅导出表达入口需有不同名称，防止误以为导出词语就包含全部学习历史。

## 4. 组件状态

| 组件 | 正常 | 操作中 / 选中 | 空态 / 错误 |
|---|---|---|---|
| 主卡 | 清晰边线、正文 | 轻微位移或翻转 | 无内容时用同尺寸简短空态 |
| 收藏 | 轮廓图标与文字 | 实心图标，短反馈 | 写入失败恢复原状态 |
| 屏蔽 | 低强调文字动作 | 移至下一张，给撤销 | 恢复操作不改变收藏 |
| 评分 | 展开答案后可用 | 提交期间禁止重复点击 | 失败留当前卡，不跳下一张 |
| 分类筛选 | 次级容器 | 清晰底色与选中语义 | 空分类显示真实数量0 |
| 模式切换 | 48dp 分段开关 | 选中块平移、主题过渡 | 不让动画产生两次加载 |
| 文件导入 | 文件选择入口 | 分析进度、预览 | 指明行号/字段与修正方法 |
| Toast/Snackbar | 不常驻 | 最短必要文本，可撤销 | 错误同时有就地提示 |

技术性错误日志放开发日志，面向用户只提供动作相关的提示。例如“第 12 行缺少内容，请补充后重试”，不显示堆栈或数据库异常类名。

## 5. 动效规格

以下为初始实现参数，属于设计方案，最终以低端设备、动画缩放和可访问性验收为准。

| 动作 | 时长 / 位移 | 规则 |
|---|---|---|
| 按钮按下 | 80–120ms；不超过0.98缩放 | 即时反馈，不等待大动画 |
| 词句模式切换 | 220–260ms | 容器颜色与选中块同步，保留页面位置 |
| 卡片翻面 | 约320ms | 中点交换正反面；避免镜像文字和闪白 |
| 左右换卡 | 180–220ms；约24dp过渡 | 轻滑入淡入，不弹簧甩动 |
| 详情展开 / 关闭 | 220–260ms | 面板位置过渡与遮罩同步 |
| 收藏反馈 | 140–180ms | 图标状态过渡，不喷粒子或放大整页 |
| 评分进入下一张 | 160–200ms | 数据写入成功后切换 |
| 设置打开 / 关闭 | 180–220ms | 返回前页保持状态 |

若系统关闭动画或应用选择减少动态效果，替换为立即状态切换或短淡入；翻面依然保留明确“查看释义”语义。动画只呈现状态，不承担业务提交。打断动画、快速连续操作或切后台后，最终显示必须与已保存状态一致。

## 6. 可访问性与设备适配

所有可操作区域至少 48×48dp，视觉图标可以小，布局必须留出真实触控面积，避免相邻点击区重叠。该尺寸遵循 Android 官方 Compose 可访问性指南。[1]

图标按钮有中文内容说明；词语/句子切换、筛选、收藏具有已选状态语义；纯装饰图像不朗读。卡片提供“查看释义”“展开详情”等可访问动作。TalkBack 下不依赖左右滑动与系统朗读导航冲突的手势完成学习。

最小验收：360dp 宽、常规字体；320dp 窄屏；系统字体 1.3倍与2倍；浅深主题；长中文句、多行标点和中英混排；手势导航与三按钮导航。字体大时评分按钮允许纵向或两行排列，但三个等级文字不可缩到不可读。

横屏和平板按最大内容宽度居中，列表可自适应，但不新增另一套语义。键盘出现时搜索结果和导入确认仍可触达。加载、空数据、错误、恢复成功均须有真实的可见状态。

## 7. 生图资产与实现边界

生成图片的用途是视觉参考、品牌氛围或必要的轻量装饰。原始参考图放项目 `img/`；文件名带用途与版本，如 `yanjian-visual-reference-v1.png`。生成记录必须包含用途、提示词、生成日期和实际文件路径，来源证据不能依靠图片里的文字。

最新参考图是本轮视觉目标，实际截图单独核对；不得以修改本文为由降低用户对参考图还原的要求。参考图中的伪数字、错字与不存在的功能不带入产品。

学习卡片的词句、来源、按钮由 Compose 原生绘制；装饰图片不覆盖正文。图片不用于伪造电影画面、演员照片、影视授权或来源核验。首版不需要下载远程图片才能打开界面。
