# 言间｜功能规格与验收条件

版本：V0.3 · 日期：2026-10-24 · 状态：实现基线  
依据：[PRD](01-PRD.md)；本文件补齐行为细节。用户明确决定之外的默认值属于执行方案，不表示已上线。

## 1. 共享对象与状态

### 1.1 关键对象

| 对象 | 必要属性 | 说明 |
| --- | --- | --- |
| 表达内容 | 稳定 ID、word/sentence、正文、短释义、发布状态、内容来源 | ID 不用列表序号或可改正文代替 |
| 来源记录 | 作品名、引用原句、媒介、语言/字幕版本、核验状态、证据 | 可一词多出处、一出处关联多表达 |
| 用户内容关系 | 收藏状态、屏蔽状态、创建/修改时间 | 收藏与屏蔽独立；屏蔽默认只影响推荐 |
| 学习状态 | 未学习或 3 个自评等级、到期时间、调度版本 | 未学习不是第四个评分按钮 |
| 评分事件 | 唯一事件 ID、内容 ID、会话 ID、评分、时间、前后快照 | 用于统计、撤销与追踪 |
| 模式偏好 | 模式、类别选择、实用比例、浏览游标 | 词语与句子独立保存 |

### 1.2 不得混用的状态

「已看」表示内容曾进入有效可见区域；「收藏」表示用户希望保留；「已会」是用户最近一次主动评价。三者可以同时存在，不能相互推导。「屏蔽」表示不再推荐，不默认取消收藏；屏蔽项仍可从收藏和屏蔽管理中打开。

「未学习」只存在于新收藏尚无有效评分的条目。顶部不熟悉/熟悉/已会三个筛选只匹配已评分条目；默认复习入口由系统队列安排到期项和未学习项。这样既保留用户确认的三栏，也不虚构初始掌握程度。

## 2. 全局模式、导航与设置

| ID | 功能 | 明确行为 | 验收 |
| --- | --- | --- | --- |
| F-G01 | 切换词语/句子 | 全界面主题和内容上下文同步变化；保留当前底部入口 | 在收藏/数据切换后仍停留同名页面 |
| F-G02 | 独立页面状态 | 每模式保存发现游标、收藏筛选、数据周期、复习队列位置 | 反复切换不把词的 ID 交给句子视图 |
| F-G03 | 底部导航 | 发现、收藏、数据；选中项有形状或文字区别 | 不只靠颜色表示当前项 |
| F-G04 | 打开/关闭设置 | 同一个右上图标作为切换按钮；关闭回来源页 | 二次点击不重复叠加页面 |
| F-G05 | 返回操作 | 优先关闭详情，再关闭设置/退出复习，最后按 Android 页面栈返回 | 返回不自动评分、不取消收藏 |
| F-G06 | 冷启动恢复 | 恢复上次内容模式和底部入口；未完成复习保留进度 | 数据不存在或版本不兼容时安全回发现页 |

设置打开时右上角图标可变为关闭符号，仍保留同一触控区域。一般偏好修改立即本地保存，显示轻量保存反馈；文件导入、备份恢复属于独立事务，必须有预览和明确提交按钮。设置关闭后内容偏好在下一次推荐生效，当前正阅读卡片不会突然消失。

## 3. 发现页

### 3.1 页面与操作

正面主要显示词或完整句子，少量页码/类型信息为次要层级。词的短释义可点击翻面查看；句子有现成短释义才展示，无释义时展示已有 usageNote 或真实来源，不为必填生成解释。来源与长解释在详情中。内容不限影视，覆盖日常和写作，来源类型分别如实显示。

| ID | 操作 | 结果 |
| --- | --- | --- |
| F-D01 | 点击卡片 | 正反翻转；翻转本身不改变收藏或复习状态 |
| F-D02 | 向左滑/下一条 | 前进到推荐序列下一条；正面默认朝上 |
| F-D03 | 向右滑/上一条 | 回到本轮实际访问过的上一条；首条时停留并轻反馈 |
| F-D04 | 向上滑/详情入口 | 展开当前内容详情，不前进到下一条 |
| F-D05 | 点击收藏 | 立即收藏，图标更新；再点取消收藏，允许撤销 |
| F-D06 | 不再推荐 | 当前条目加入屏蔽，移向下一项；短提示可撤销 |
| F-D07 | 推荐池为空 | 说明已无符合条件内容，给出调整偏好和导入入口 |
| F-D08 | 本轮已看完 | 显示本轮完成状态，用户选择下一轮再安排重复 |

屏蔽动作不使用可能与翻卡冲突的长按或滑动。撤销屏蔽恢复条目可推荐性，并可回到原卡。取消收藏保留历史评分用于可恢复记录，当前收藏集合及待复习集合立即移除；再次收藏恢复原学习状态，除非用户在详情中明确选择重置学习记录。

### 3.2 推荐细则

按「正式发布、当前模式、用户已选领域、用途标签、未屏蔽」形成候选池。本轮复用收藏/评分组件，收藏内容仍可推荐；不声称已实现未收藏优先策略。

句子默认实用比例 0.60，经典比例 0.40。本轮采用最多 100 条的稳定加权队列，供应充足时每 100 条为目标比例；0% 完全排除实用，100% 完全排除经典。队列只在取完或偏好变更后的下一次推荐重建，Compose 重组不重洗，队列内 ID 去重。词语不受句子比例影响。

所需任一主类完全为空时展示明确空态，不静默改成另一主类；供应耗尽时当前有界队列结束，下一次取队列仍遵守原比例。领域多选取并集，领域全不选或日常/写作用途全不选均为空池。保存原始比例，不因供应不足永久改写。模式、比例、领域、用途与每模式/类型浏览游标本地持久化；偏好下一次取新推荐生效，当前卡片不突然消失。

## 4. 详情页

| ID | 信息区 | 约束 |
| --- | --- | --- |
| F-T01 | 表达与短释义 | 顶部能识别正在查看的条目 |
| F-T02 | 原句和作品名 | 原句原样呈现；作品名与核验状态相邻，未知字段不伪填 |
| F-T03 | 原始语境 | 说明人物意图、语气、背景；剧透可折叠，编辑说明与原句分开 |
| F-T04 | 怎么用 | 适用/不适用场景、自然度说明、近反义差别；示例注明原创 |
| F-T05 | 来源更多信息 | 剧集、版本、证据链接等按需展开，首版无播放器 |
| F-T06 | 数据操作 | 收藏、屏蔽、个人条目编辑、学习记录重置等按权限显示 |

详情默认在半屏或接近全屏的独立面板中呈现，由可见关闭按钮和系统返回键关闭。正文内部滚动与面板拖动分离；只有内容滚到顶且从面板拖拽区域下滑才关闭。官方条目不能直接编辑正文；复制为个人条目后可改，保留派生关系，不能继承已核验状态。

## 5. 收藏页与搜索

收藏列表显示正文、短释义摘要和最新掌握状态。搜索只搜索本机已安装官方内容与用户内容中可访问字段；收藏页默认限定收藏集合，不把全库结果混进来。

| ID | 功能 | 规则 |
| --- | --- | --- |
| F-C01 | 排序 | 最近收藏为默认，可选到期优先和掌握程度 |
| F-C02 | 状态筛选 | 全部、未学习、不熟悉、熟悉、已会；可另切仅到期 |
| F-C03 | 搜索 | 支持正文、短释义、作品名、标签；空白搜索等同无过滤 |
| F-C04 | 开始复习 | 当前模式下到期队列；无到期但有未学习则开始学习 |
| F-C05 | 查看任意内容 | 点击行进入详情；阅读不写入评分 |
| F-C06 | 取消收藏 | 可撤销；退出学习队列，保留历史事件供恢复 |
| F-C07 | 手动练习 | 无到期时显示「自由练习」，与完成到期复习清楚区分 |

主「开始复习」使用当前模式的完整到期集合，不悄悄受搜索文字影响。用户在筛选列表中选择「练习当前结果」才以筛选结果建队列。没有到期且没有未学习内容时，不制造到期任务；显示「本轮已完成」，另给自由练习入口。

## 6. 复习页

### 6.1 队列与等级

顶部固定三个分类入口「不熟悉、熟悉、已会」，计数显示该类当前待复习数。默认全队列状态不高亮三者；轻量标题说明「今日复习」或「首次学习」。点击一个分类筛到已评分且到期的内容，再点击同一个已选分类取消筛选，回到本次会话剩余队列。不引入第四个顶部大分区。

新内容的首次学习在默认队列中出现，可用小标签「初次」表示，评分后才有三个等级之一。进入某个空分类时显示「这一类暂时没有到期内容」，允许返回全队列或进入该类自由练习，不能自动切换其他分类。

| ID | 事件 | 数据变化 | 页面变化 |
| --- | --- | --- | --- |
| F-R01 | 翻卡 | 仅改变当前卡 reveal 状态 | 正面与短释义翻转 |
| F-R02 | 上滑详情 | 记本次已揭晓，未写评分 | 展开原句和详情 |
| F-R03 | 底部评分 | 单次原子写评分事件、最新等级、下次到期 | 成功后进入下一张 |
| F-R04 | 左滑跳过 | 本会话暂存 skipped，不写评分 | 移到下一张，尾部可再看 |
| F-R05 | 右滑返回 | 回看会话上一张，不自动撤销既有评分 | 已评分卡展示其结果和撤销入口 |
| F-R06 | 撤销最近评分 | 恢复该事件前学习快照；统计抵扣；事件留痕 | 返回被撤销卡，允许重新作答 |
| F-R07 | 切换顶部分类 | 保存当前游标并变更视图过滤 | 不修改任何内容等级 |
| F-R08 | 退出/切换模式 | 保存会话草稿与位置 | 不给未评分卡默认评级 |

只有在当前卡至少一次揭晓答案后才启用评分；再次翻回正面不收回评分权限。未揭晓时底部按钮可隐去或禁用，不出现长篇解释。点开详情等价于揭晓。底部评分提交期间锁定；以事件 ID 与事务处理双击，不依赖动画节流保证数据正确。

### 6.2 调度、自由练习与异常

正式版本计划采用 FSRS 方向的本地调度；工程映射暂定「不熟悉 → Again（1）、熟悉 → Hard（2）、已会 → Good（3）」，不对用户暴露 Easy。该映射是待内容内测的执行方案，不是用户已确认的算法参数。首轮实现可使用明确标注的演示调度；在真实接入并验证前，界面和交付报告均不得宣称已采用 FSRS。执行时保留原始评分、前后状态及模型版本，为后续算法迁移留余地；不能随便把「不熟悉」等同于某个固定小时数写成正式记忆规律。

自由练习可以翻卡和查看详情，默认不改变正式到期时间，也不计入「完成到期复习」。若允许自由练习评分，应显式切入会更新计划的练习会话，并在开始前说明；第一版默认采用仅浏览练习，避免提前反复刷卡扭曲调度。

评分保存失败时停留当前卡，显示短错误与重试入口，恢复按钮可用；不能先推进再丢失记录。队列清空时展示实际完成数、跳过数、新学习数。还有跳过项则提供「继续 N 条」，不展示全部完成。会话中更新官方内容若移除了某项，使用退役记录或用户快照继续可读，不崩溃或串 ID。

## 7. 数据页

默认今天，可切近 7 天、近 30 天、全部。时间按用户设备当地日界线归属；事件保存绝对时间和记录时区，旅行/改时区后的口径由技术方案固定并在测试覆盖。模式切换只统计当前内容类型，不能把全库总量当当前模式数据。

行为指标依照 PRD：浏览内容数、有效复习次数、复习内容数、期间新增收藏。另设「当前收藏」和「当前掌握」展示最新存量，不受历史日期筛选歪曲。掌握环图包括未学习，不能因排除未学习夸大已会比例。

趋势图优先画真实每日复习记录；记忆保持曲线仅在模型有数据且可说明估计含义时显示，并明确「模型估计」。第一版若尚无可靠模型，直接隐藏该图，保留复习趋势；空状态简短写「完成复习后出现记录」。演示数据必须与真实记录隔离，不能在安装后制造连续打卡或虚假学习数。

## 8. 导入、导出与备份

### 8.1 内容导入（执行方案）

| ID | 步骤 | 规则 |
| --- | --- | --- |
| F-I01 | 选择文件 | 明确列出当前支持格式和大小上限；使用用户选择的文件 |
| F-I02 | 解析与字段匹配 | CSV 可匹配正文、释义、类型、作品名、原句、标签；编码错误能说明 |
| F-I03 | 预览 | 展示有效/重复/缺字段/无效行数量与样例，不立即写库 |
| F-I04 | 去重决策 | 默认跳过完全重复项；同正文不同来源提示可合并来源或保留独立个人记录 |
| F-I05 | 确认提交 | 原子批次写入；失败回滚，成功给批次 ID、成功数和跳过数 |
| F-I06 | 导入撤销 | 仅撤销本批新建与明确变更项，后续已修改内容需提示冲突 |
| F-I07 | 导入后归属 | 默认进入「我的内容」，用户可勾选同时收藏；不自动标已核验 |

TXT 默认每个非空行是一条正文；类型按简单规则初判但允许用户改；缺释义不编造，标记待补充。CSV/JSON 保留多行与标点，不擅自压平影视原句。重复判断使用规范化检索键，但原始展示文本原样保存。官方条目与个人条目身份分开，即使文字一致也不能覆盖官方来源或用户旧记录。

### 8.2 导出与完整备份

内容导出用于交流，完整备份用于恢复，两个入口命名必须区分。导出 CSV/JSON 可包括正文、释义、标签、作品与原句；完整备份还包括用户内容 ID、收藏、屏蔽、评分事件、学习状态、偏好、版本信息和校验摘要。CSV 不承担完整学习历史恢复职责。

首版完整备份恢复采用**替换当前用户域**：先完整校验版本、摘要和引用，再展示影响预览；确认后在同一 Room 事务内保存当前恢复点并替换个人内容、用户关系、事件、会话及偏好快照，保留当前官方内容。失败回滚原用户状态；恢复点可从设置再次预览恢复。首版不合并多设备学习日志，不接受普通内容文件更新官方库。

## 9. 本地内容管理工具

内容制作工具与手机 App 分离，是本地工作工具。内容流转为「草稿 → 待核验 → 已核验 → 可发布 → 已发布/退役」，核验与可发布是不同条件。编辑可以录入词句、解释、出处证据、语言与标签；审核只在证据完整时变更状态。

发布前批量检查 ID 唯一性、必填字段、原句与目标词关联、类别、来源、状态与内容包版本。AI 可生成候选及编辑说明，必须标注生成来源并由人审核；工具中的「已核验」操作不代表工具自动证明台词真实性。首版可从受校验的结构化文件与导出脚本起步，再补可视化编辑界面。

## 10. 验收用例总览

| 用例 | 场景 | 预期 |
| --- | --- | --- |
| QA-01 | 词语收藏页切句子再切回 | 页面、筛选和数据各自恢复 |
| QA-02 | 卡片轻点、斜滑、连续点 | 一次手势只触发一种动作；无误评分 |
| QA-03 | 顶部点击已会分类 | 到期列表改变，任何条目评分不变 |
| QA-04 | 底部已会双击 | 只生成一个有效评分事件，推进一张 |
| QA-05 | 跳过后返回与重启 | 无虚增复习次数，队列位置可恢复 |
| QA-06 | 评分后撤销 | 等级、到期时间、统计与队列一致回滚 |
| QA-07 | 无到期但有初学 | 进入首次学习，不声称有到期任务 |
| QA-08 | 全部屏蔽或筛选空 | 清楚空态，可调整筛选或恢复屏蔽 |
| QA-09 | 关闭设置再次打开 | 修改保存；来源页未丢失；没有多层设置栈 |
| QA-10 | CSV 多行、重复、缺列、坏编码 | 预览能解释错误；未确认前数据库不变 |
| QA-11 | 备份恢复中断或版本不支持 | 原用户数据保持可用，无半份恢复 |
| QA-12 | 官方内容更新与退役 | 收藏、个人内容和学习记录不被覆盖 |
| QA-13 | 首次安装数据页 | 无伪造数据或个人预测曲线 |
| QA-14 | 超长句、系统大字体、减弱动态 | 仍可读、可操作，不丢正文 |

具体已通过的用例必须由执行记录支撑。本文件只规定目标，不替代测试结果。
