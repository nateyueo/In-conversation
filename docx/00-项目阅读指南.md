# 言间｜项目阅读指南
版本：V0.3 · 整理日期：2026-10-24 · 目标平台：Android · 项目代号：言间（未定正式名称）

## 项目是什么
用真实影视语境帮助用户学习、理解并主动使用中文词语和句子。主要服务日常聊天与情感表达。词语与句子使用同一套学习逻辑，但拥有独立的浏览、收藏和复习状态；浅色词语模式与深色句子模式全局切换。

第一版离线使用，无强制登录、数据库服务器或 App 内 AI 接口。运行数据是本地文字；影视原声、画面与视频留到后续。官方内容重视出处核验，个人导入允许自由扩展，两者不混淆。

## 来源与效力
本轮依据当前会话中提供的历史聊天内容和用户最新指令整理。历史文本中的图片附件与旧 HTML 文件没有随本轮文件提供，不假定已读取其像素或源码。新设计以已明确的交互要求为基础重新制作。

文档区分：
- **用户已确认**：历史用户文字与本轮指令明确表达。
- **本轮实施方案**：为开始开发而选择的具体行为、技术与边界，可通过实际体验调整。
- **待实测 / 后续**：不能算成已交付承诺。
文档以最新用户决定优先。历史 AI 建议不是自动获得用户确认；详见决策记录。

用户指定工程路径为 `D:\\AI-USE\\Android\\chengyu`。Markdown 文档放 `docx`，图像放 `img`。目录叫 docx，但文件后缀按要求全部为 .md。历史服务使用既定的 `docs/history-session`，不移动或手工重命名历史档案。

## 工程分工
| 角色 | 责任与输出 |
|---|---|
| 产品负责人 | 管理需求、范围、优先级与体验验收 |
| 视觉与交互 | 维护设计规范、关键页面及可访问性 |
| Android 开发 | 实现离线界面、数据、导入、复习与备份 |
| 内容编辑 / 审核 | 收集候选、核验原句和作品、保留证据 |
| 测试 | 核验业务闭环、数据完整性、兼容性与恢复流程 |
| 技术负责人 | 管理架构、依赖版本、构建、发布门槛 |

小团队可以兼任，内容录入与发布核验仍需可追溯。第一版内容管理是制作侧本地工具，不搭建在线服务。

## 工作区约定
优先阅读根目录 [AGENTS.md](../AGENTS.md) 和 [本机App开发环境.md](../本机App开发环境.md)。使用现有 Windows JDK / SDK / Gradle，不随意升级全局环境。开发文件与生成图像采用稳定命名。草稿内容、样例数据、已发布内容有明确区分。严禁为演示体验伪造“已核验”的影视出处、真实学习统计或记忆预测曲线。

## 当前基线
当前是从空工程开始的规划与首个实现轮次。首轮目标是文档、生成的视觉参考，以及按新风格制作的 Android 可操作初版；正式内容数量、完整 FSRS、所有导入格式和内容管理工具不在没有验收证据时标记完成。实际状态以 10 号文档为准。
