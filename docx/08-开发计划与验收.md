# 开发计划与验收
版本：V0.3 · 日期：2026-10-24 · 性质：本轮实施计划，非固定排期承诺

## 交付顺序
先完成文档，再生成视觉参考，随后实现 Android 首个闭环。每个阶段使用可打开的成果和实际验证记录交接。不能用“源码已生成”代替“构建通过”，也不能用“APK 已生成”代替“设备运行通过”。

| 阶段 | 交付 | 完成门槛 |
|---|---|---|
| M0 规划基线 | 00—09 Markdown 文档 | 交互、数据、来源与首版范围无冲突，关键行为可验收 |
| M1 视觉与可操作初版 | 生图参考、Android 工程、可编译界面与离线样例 | 词句切换、卡片、详情、收藏、复习、数据和设置可以连贯操作；明确样例身份 |
| M2 数据闭环 | 正式 Room 数据结构、导入预览、导出备份、恢复、官方内容包 | 重复导入幂等、事务失败不污染数据、更新不覆盖学习记录 |
| M3 真实内容与调度 | 经核验种子内容、正式间隔算法、生产工具 | 来源与授权记录完整、调度版本固定并有基准验证；不造个人曲线 |
| M4 内测与发布候选 | 设备验收、迁移和异常测试、发布包 | 验收表通过，未完成功能明确隐藏或标记，正式签名和发布另行执行 |

M1 可以提前实现一部分 M2；不因此声称所有数据能力已完成。开发阶段本地原创示例可用于界面与交互验证，不能计入官方影视内容规模。

## 本轮实施范围
本轮首先实现一个真正的 Android 起步版本，目标包括：
- 全局词语 / 句子切换、对应浅深主题，以及发现 / 收藏 / 数据三个入口。
- 大卡片浏览、点击翻面、详情展开与系统返回，明确可点按钮作为手势替代。
- 收藏、取消收藏、屏蔽与恢复；本地保存，不随 App 重启丢失。
- 由收藏进入复习，顶部分类与底部评分分开，未揭晓不能评分；本次评分不能重复写入。
- 今日 / 近七天数据来自实际行为。初始无历史时显示真实空状态。
- 右上设置按钮再点一次关闭，关闭后回到原页面；推荐比例有本地偏好存储。
- 文件导入与备份若本轮接入，则提供成功、错误、重复与恢复结果；未接入则写明，不保留假成功按钮。
- 生成参考图保存到 img，文档保存到 docx，交付记录提供实际构建命令和退出码。

正式影视内容包、经过实测的 FSRS、自动版权判断、视频原声、在线运营后台均不得用模拟数据伪装完成。

## 测试取舍
优先验证会导致数据丢失、重复评分或错误来源的逻辑；低风险颜色和间距调整通过截图与设备观察验证，不为静态 UI 文案堆叠无效单元测试。规则层测试使用固定时钟、稳定输入和明确结果。构建只重复到解决已发现的问题为止。

## 内容规模与进度
此前“内测 300—500 词语、100—200 句子”“正式 1,000—1,500 词语、300—500 句子”均属于建设建议，不是库存。先进行真实筛选试验，统计候选量、核验通过量、重复率、编辑耗时和自然表达评价，再决定实际首发量。
优先中文电影、电视剧、纪录片，书籍作为补充。外语字幕必须保留版本来源。数量不能补偿来源或使用价值缺陷。

## 构建与发布
在用户现有 JDK 17、Gradle 8.13、主 SDK API 36 上锁定可兼容组合。AGP 8.13 官方兼容表列出 Gradle 8.13、JDK 17 和最高 API 36.1；最终依赖版本以项目配置和实际构建为准。[官方兼容说明](https://developer.android.com/build/releases/agp-8-13-0-release-notes)（2026-10-24核验）

先完成 debug 包。模拟器安装与运行属于本地验证；不执行商店上传、公开发布、正式签名或接入收费服务。构建日志、测试结论与未验证项写入本轮交付记录，不输出“全部通过”一类没有范围的结论。

## 主要风险与处理
| 风险 | 对应措施 |
|---|---|
| 视觉漂亮但功能无法映射 | 图片只作风格参考，布局和点击区由真实 Compose 组件实现 |
| 数据实际质量不足 | 早期小批核验，按通过率与编辑成本估算规模 |
| 数据更新误伤学习进度 | 内容与学习数据分离，稳定 ID，禁止破坏性迁移用户库 |
| AI 编造影视出处 | 原句必须有证据，AI不能直接发布，演示内容明确标识 |
| 复习指标误导 | 分离当前掌握存量与期间事件，明确示例算法和正式调度 |
| 首版被大量格式拖延 | CSV / JSON / TXT 优先，其余按数据规范阶段实现 |
| 工具清单与实机不同 | 用本项目构建和设备证据验收，不安装重复工具链 |
