# 本轮交付与运行记录

版本：V0.2 文本内容接线 · 日期：2026-10-24

## 本轮结果

- 在现有原生 Compose 界面接通生产 JSON→生成 assets→后台流式验证→Room 单事务激活→推荐、收藏、评分和重启保留。移除两处空库播种，不再将测试 fixture 当初始词库。
- 生产唯一输入 `data/processed/official-content.json`，构建生成 `app/build/generated/officialAssets/content/official-content.json`。data 由数据负责人维护，工程不手工双份编辑。包未就绪或损坏时明确提示，旧收藏继续可读。
- Room v1→v2 显式迁移保留 entries 与 user_entries；增加修订、活动内容版本、标签、来源和 content_manifest。旧样例如实显示自制原创，仅退出正式推荐池。
- 导入检查重复 ID、字段与发布状态、来源声明及版本冲突，失败全包回滚；同版本只校验不增量覆写。收藏仅切换 isFavorite，保留掌握程度、复习次数、上次复习时间与屏蔽状态。
- 比例、领域、日常/写作用途、模式与浏览游标已持久化。句子使用最多 100 条稳定加权队列，严格 0/100，空池不静默换类；词语不受句子比例影响。领域和用途全不选明确为空。收藏每次 100 条加载更多，统计不把当前已加载页当总量。
- 来源显示区分词典、社区例句、公共领域、自制原创、影视；句子无释义展示已有 usageNote 或真实来源，不补造释义。详情包含离线来源、署名、许可和核验声明。

## 当前取舍与未完成范围

- 单库分表减少旧安装迁移与跨库激活的复杂度，接受内容事务导入期间的写锁；双物理库为后续，不宣称当前已分库。
- 两次流式读取支持 JSON 属性顺序独立，避免一次全量文本解析；接受一次完整包校验 IO、每条查询及 ID 集合内存。推荐有界，SQL 标签过滤与游标排序的真实设备延迟仍待测。
- 稳定加权序列保证可重复验证和队列内无重复，有限库存后可再次浏览；未实施随机近义分散。缺少所需主类时保留用户偏好并提示，不自动改变比例。
- 复用现有三等级复习界面，评分保存掌握程度与次数；尚无正式 FSRS、可回放事件、撤销、到期调度、完整会话恢复。已有初学状态细化、手势与屏蔽撤销仍为原规划待实现项，不因本轮内容接线改称已交付。
- CSV/JSON/TXT 个人导入、导出备份、恢复、搜索与正式内容管理 UI 未在本轮接入。来源事实和逐条内容质量由数据生产验收承担；source_checked 不冒充严格 verified。
- 保留上一轮生成的视觉参考；本轮不修改 img，不把设计参考当实机画面。

后续先完成可用设备验收与真实规模性能测量，再按用户顺序推进上述未完成功能；本轮不做 Git 提交或推送。
