## 本机运行

1. 使用 Android Studio 打开项目根目录，或在 PowerShell 进入项目目录。
2. 运行 `\.\gradlew.bat :app:assembleDebug`；首次构建需网络下载 Gradle 依赖。
3. APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
4. 安装与启动需有可用设备或模拟器：`adb install -r app/build/outputs/apk/debug/app-debug.apk`，再用 `adb shell monkey -p com.yanjian.app 1` 启动。

本轮实际构建成功；首次构建前需联网下载 Gradle 依赖。`adb devices -l` 的实际输出为空，没有已连接设备；`adb install` 仍需连接设备或启动模拟器后再执行。
