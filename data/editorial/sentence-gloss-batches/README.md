# 句子释义批次

本目录保存 DeepSeek 逐条补写的29,552条句意及定向修正成果，已在2026-10-24合并进 `data/editorial/sentences.psv`。v4补齐全量句意，v5进一步修订遗漏的184条古典白话。正式发布以 `data/processed/official-content.json` 为准，不直接读取批次目录。

## 生成要求

- 逐条理解原句并写自然简体中文，6–60 字符，通常 12–40 字；短句不为字数添加废话。
- 稳定ID与原有出处不变；已有83条释义不覆盖。正文只允许按有据校改表定点修复，本轮新增一处「器→哭」。
- 保留人物关系、否定、条件、数量、时间、可能性及疑问/请求/命令语气；不擅自替原作者改正文，不增添背景、性别、动机或哲理。
- 实用句用明白的近义表达；古典句解释关键古词和典故语义，不能仅转换繁简、删字或调整词序。
- 不照抄原句，不用“这句话表达了”“意思是”等空壳，不以模板、词表替换或原文拼接程序生成释义。
- 模型逐条生成；程序只负责分批、对齐、结构与覆盖检查。疑难条目单列 `uncertainties.jsonl`，不可用占位文字充数。

## 文件与检查

每行 JSON：`{"id":"…","text":"…","shortMeaning":"…","authoredOn":"YYYY-MM-DD"}`。目录分片的 ID 不应重叠。

运行 `python data/scripts/merge_sentence_gloss_batches.py` 只检查；`--sample <路径> --seed <整数>` 输出随机分层 50 条（实用 35、古典 15）；`--apply` 只在全部未覆盖句子均有合格结构的批次后合并至 `data/editorial/sentences.psv`。
