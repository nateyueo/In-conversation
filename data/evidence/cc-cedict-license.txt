<h2 class="sectionedit2" id="what_is_cc-cedict">What is CC-CEDICT?</h2>
<div class="level2">

<p>
CC-CEDICT is a continuation of the CEDICT project. The objective of the CEDICT project was to create an online, downloadable (as opposed to searchable-only) public-domain Chinese-English dictionary. CEDICT was started by Paul Andrew Denisowski in October 1997. For the most part, the project is modeled on Jim Breen&#039;s highly successful EDICT (Japanese-English dictionary) project and is intended to be a collaborative effort, with users providing entries and corrections to the main file.
</p>

<p>
CC-CEDICT is licensed under a <a href="https://creativecommons.org/licenses/by-sa/4.0/" class="urlextern" title="https://creativecommons.org/licenses/by-sa/4.0/" rel="ugc nofollow">Creative Commons Attribution-Share Alike 4.0 License</a> (click the link for detailed information).
</p>

</div>

<h2 class="sectionedit3" id="add_improve_cc-cedict_s_content">Add / improve CC-CEDICT&#039;s content</h2>
<div class="level2">

<p>
CC-CEDICT&#039;s content can be changed in the following ways:
</p>
<ul>
<li class="level1"><div class="li"> Through the MDBG Chinese-English dictionary (single entries only):<br/>
<a href="http://www.mdbg.net/chinese/dictionary" class="urlextern" title="http://www.mdbg.net/chinese/dictionary" rel="ugc nofollow">http://www.mdbg.net/chinese/dictionary</a> <em>(search the entry to be changed in the dictionary and click the pencil icon in the ⋮ menu in the result table)</em></div>
</li>
<li class="level1"><div class="li"> Through the CC-CEDICT editor website (both single entries and batches):<br/>
<a href="http://cc-cedict.org/editor/editor.php" class="urlextern" title="http://cc-cedict.org/editor/editor.php" rel="ugc nofollow">http://cc-cedict.org/editor/editor.php</a></div>
</li>
</ul>

<p>
Changes will be reviewed by editors.
</p>

</div>
