# 外国经典电影短台词｜个人导入包

本目录文件用于言间 App 的个人内容导入，与 `data/processed/official-content.json` 官方发布包分开维护。

## 使用

将 `foreign-classic-film-quotes-v1.json` 复制到手机，在言间右上角设置中进入“我的内容、导入与备份”，选择 **JSON**，选文件后点击“解析并预览”。核对数量与错误后，可勾选“同时收藏”，再确认保存。导入会新增个人内容，不覆盖官方词库。

这是 UTF-8 JSON 文本，共100条现成中文短台词，每条包含中文原句 `text`、原创句意解释 `shortMeaning`、标签，以及 `source` 中的电影名称、与 `text` 相同的中文原句和来源页面。中文台词摘自公开中文台词网页并逐条对照，**未核对具体发行字幕版本**，来源网站也不据此称为官方字幕来源。具体片名及页面链接见各条记录。

## 内容与来源边界

每部电影最多摘录两条完整短句，每条不超过30字，每部合计不超过45字；中文原句以公开中文台词页面对照，不作英文台词自译。页面匹配不等于逐片观看核验，亦不证明页面与最终上映台本完全一致。选取的是简短摘录，不是完整剧本、整场对话或字幕文件。电影台词涉及原作品权利，不将其标为公有领域、项目原创或开放许可；原创的是本次中文句意解释。

## 后续追加

- 保持顶层 `format=yanjian-content`、`schemaVersion=1`。
- 保持 `packageId=yanjian-foreign-classic-film-quotes-v1`。
- 现有条目的 `externalId` 不变；追加内容使用尚未占用的编号。
- 修改已有条目的释义后重新导入，预览可选择更新同键内容或保留原条。
- `shortMeaning` 不能用电影名或网址代替；有真实释义才可进入学习评分。
- 完整文件重复导入不会再次写入；新版文件中的未变条目在预览中跳过重复。
